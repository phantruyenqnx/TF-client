# @tf/studio-base

This package contains core components used in TF Studio.

## Usage

When contributing to the TF Studio codebase, you can import from `@tf/studio-base` at its top-level or from lower in its directory:

```ts
import { ExtensionInfo, ExtensionLoaderContext, ExtensionLoader } from "@tf/studio-base";
import fuzzyFilter from "@tf/studio-base/util/fuzzyFilter";
```

For a full list of the package's exports, reference its [`index.ts` file](packages/studio-base/src/index.ts).
